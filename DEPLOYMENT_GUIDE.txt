5. MYSQL DATABASE SETUP
================================================================================

STEP 1 — Create a Database
  • In cPanel, find "MySQL Databases"
  • Under "Create New Database", type a name e.g. clothingstore
  • Full name will be: if0_XXXXXXX_clothingstore
  • Click "Create Database"

STEP 2 — Create a Database User
  • Scroll down to "MySQL Users"
  • Enter a username e.g. luxeuser
  • Set a strong password
  • Click "Create User"
  • Write down the username (if0_XXXXXXX_luxeuser)

STEP 3 — Link User to Database
  • Scroll to "Add User to Database"
  • Select your user and database
  • Click "Add"
  • On next screen, click "ALL PRIVILEGES" then "Make Changes"

STEP 4 — Note Your DB Host
  • Go back to cPanel main page
  • Look for "MySQL Databases" or check welcome email
  • Host is something like: sql309.infinityfree.com
  • Write it down — you need it in config.php

6. CONFIG.PHP — HOW TO FILL IT
================================================================================

Open: clothing-store/config.php

Change these lines with YOUR real values:

  define('DB_HOST', 'sql309.infinityfree.com');   // Your MySQL host
  define('DB_NAME', 'if0_12345678_clothingstore'); // Your database name
  define('DB_USER', 'if0_12345678_luxeuser');      // Your DB username
  define('DB_PASS', 'YourStrongPassword123');       // Your DB password

  define('SITE_URL', 'https://Gujjus.rf.gd');    // Your site URL (no trailing slash)
  define('DEBUG_MODE', false);                      // Keep false on live site!

IMPORTANT: Never share config.php publicly. Never upload it to GitHub.

7. UPLOAD FILES VIA FILEZILLA (FTP)
================================================================================

STEP 1 — Install FileZilla
  • Download free from: https://filezilla-project.org

STEP 2 — Get FTP Credentials
  • In InfinityFree cPanel, find "FTP Accounts"
  • Note the FTP host, username, and password
  • Port is usually 21

STEP 3 — Connect in FileZilla
  • Open FileZilla
  • Host: your FTP host (e.g. ftpupload.net)
  • Username: your FTP username
  • Password: your FTP password
  • Port: 21
  • Click "Quickconnect"

STEP 4 — Upload Files
  • On the right panel, navigate to: /htdocs/
  • On the left panel, find your clothing-store/ folder
  • Select ALL files inside clothing-store/
  • Drag them to the right panel into /htdocs/
  • Wait for upload to complete

11. COMMON ERRORS & FIXES
================================================================================

ERROR: "Database Connection Failed"
  FIX: Check config.php DB_HOST, DB_NAME, DB_USER, DB_PASS
       Make sure the DB user is linked to the database

ERROR: "404 Not Found" on pages
  FIX: Make sure files are inside /htdocs/ not outside
       Check SITE_URL in config.php has no trailing slash

ERROR: White blank page
  FIX: Temporarily set DEBUG_MODE to true in config.php
       Check PHP error in browser, fix it, then set back to false

ERROR: Images not showing
  FIX: Check that uploads/ folder exists and is writable
       Check UPLOAD_DIR path in config.php

ERROR: "Permission denied" on uploads
  FIX: In File Manager, right-click uploads/products/
       Choose "Change Permissions" → set to 755

ERROR: Session/Login not working
  FIX: InfinityFree supports PHP sessions. If issues:
       Add session_save_path('/tmp') at top of config.php

ERROR: .htaccess issues
  FIX: InfinityFree supports .htaccess. Create one in /htdocs/:
       Options -Indexes
       DirectoryIndex index.php

ERROR: "Call to undefined function" errors
  FIX: Make sure require_once paths are correct
       All includes use __DIR__ which is safe

ERROR: Form submissions not working
  FIX: Check CSRF token is in the form
       Make sure form action URL is correct

12. SECURITY CHECKLIST
================================================================================

  ✓ config.php has real DB credentials (never share)
  ✓ DEBUG_MODE = false on live site
  ✓ All queries use PDO prepared statements (already done in db.php)
  ✓ Passwords are hashed with password_hash() (done in auth files)
  ✓ Admin panel checks isAdmin() on every page
  ✓ CSRF token on all forms
  ✓ File uploads validate type and size
  ✓ User inputs are sanitized with e() / htmlspecialchars()
  ✓ session_name() set to custom name (done in functions.php)

  OPTIONAL EXTRAS:
  • Add .htaccess to block direct access to includes/:
      deny from all
  • Add rate limiting on login form (limit 5 tries)
  • Enable HTTPS in InfinityFree cPanel → SSL/TLS

13. OPTIMIZATION TIPS
================================================================================

PERFORMANCE:
  • Use placeholder images from picsum.photos or unsplash until you have real ones
  • Keep CSS in one file (style.css) — already done
  • Minify CSS/JS before going live (use: https://minifycode.com)
  • Use WebP format for all product images
  • Compress images before upload (use: https://squoosh.app)

SEO:
  • Each page has unique <title> and <meta description>
  • Use <h1> only once per page
  • Add alt text to all images
  • Keep URL structure clean

MOBILE:
  • All CSS uses mobile-first media queries
  • Navbar has hamburger menu for mobile
  • Test on actual phone using your live URL

FREE HOSTING LIMITS (InfinityFree):
  • 5 GB storage
  • No Node.js / no npm
  • PHP 7.4+ supported
  • MySQL 5+ supported
  • 50,000 hits/day limit
  • No shell/SSH access
  • Upload max file size: usually 10MB per file
