Project Overview

What is Gujju Clothing?

A Complete Online Fashion Store

Gujju Clothing is a full-featured, responsive, database-driven e-Commerce web application designed to showcase and sell premium apparel, ethnic wear, western outfits, and fashion accessories.

Built with PHP and MySQL, it delivers a secure, modern retail experience with multi-attribute filtering, real-time stock management, coupon discounts, and a comprehensive admin panel.

Why We Built It

Many clothing brands and apparel styles are active in the market — Gujju Clothing brings them all to one store.

Customers can browse 24/7, check live stock, apply promo discounts, and place orders securely.

How It Works

The Problem

Why Do We Need This Platform?

Problem 1

Geographic Limits

Physical stores are limited to local foot traffic and fixed operating hours, restricting growth.

Problem 2

Manual Billing Errors

Paper receipts and disconnected spreadsheets cause billing errors and slow order processing.

Solution

Digital Fashion Store

A 24/7 accessible platform with live stock, automated billing, and real-time order tracking.

The Core Challenge

Traditional clothing businesses lose customers due to restricted access and poor digital presence. Gujju Clothing eliminates these barriers with a fully digital, responsive, and secure platform that works around the clock.

Project Objectives

What We Aim to Achieve

24/7 Digital Storefront

Enable customers to browse and purchase clothing anytime, anywhere — without physical store constraints. A complete e-commerce platform replacing traditional retail limitations.

Secure Authentication

Implement Bcrypt-encrypted user registration, session management, and role-based access for customers and admins.

Advanced Product Catalog

Multi-attribute filtering by brand, category, gender, price range, size, and color with live search suggestions.

Automated Billing & Invoicing

Generate formal, printable PDF/HTML order invoices with detailed tax, discount, and line-item breakdowns automatically.

Order Tracking System

Allow customers to track real-time fulfillment status — Pending → Processing → Shipped → Delivered.

Core Modules

The system is divided into two primary modules based on user roles and responsibilities.

Admin Module

  • Full dashboard with sales & revenue metrics
  • Manage products, categories & brands (CRUD)

Capabilities

Key Features

A complete suite of tools for an exceptional shopping and management experience.

Secure Authentication

Bcrypt-encrypted login for customers and admins with session-based access control.

Multi-Category Catalog

Browse Men's, Women's, Kids', Ethnic & Western wear with advanced filters and live search.

Cart & Wishlist

AJAX-powered cart with real-time quantity updates, subtotal calculations, and wishlist bookmarking.

Coupon & Discount

Promo code validation with percentage or fixed discounts, minimum order rules, and usage limits.

Invoice Generation

Automated printable HTML/PDF invoices with itemized tax, discount, and shipping breakdowns.

Low Stock Alerts

Admin receives automatic visual warnings when product quantity falls below the minimum threshold.
