PART 1 — RUN THE SITE LOCALLY ON XAMPP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1 — Install & Start XAMPP
──────────────────────────────
1. Download XAMPP from: https://www.apachefriends.org/download.html
   (Choose PHP 8.x version)

2. Install it (default path: C:\xampp)

3. Open "XAMPP Control Panel"

4. Click START next to:
   ► Apache  (Port 80)
   ► MySQL   (Port 3306)

   Both should turn GREEN. If port conflict → see ERROR FIXES section below.


STEP 2 — Copy Your Project Files
─────────────────────────────────
1. Open File Explorer and go to: C:\xampp\htdocs\

2. Create a NEW FOLDER named exactly: cshop
   Full path will be: C:\xampp\htdocs\cshop\

3. Copy ALL your project files from "d:\i test\" into: C:\xampp\htdocs\cshop\
   The folder should contain:
     ✔ index.php
     ✔ config.php
     ✔ .htaccess
     ✔ admin\ folder
     ✔ assets\ folder
     ✔ auth\ folder
     ✔ cart\ folder
     ✔ database\ folder  (contains schema.sql and upgrade_products.sql)
     ✔ includes\ folder
     ✔ pages\ folder
     ✔ uploads\ folder


STEP 3 — Create Local MySQL Database
──────────────────────────────────────
1. Open your browser and go to: http://localhost/phpmyadmin

2. Click "New" on the left sidebar

3. Database name: cshop_local
   Collation: utf8mb4_unicode_ci
   Click CREATE

4. Click on "cshop_local" in the left sidebar

5. Click the "Import" tab at the top

6. Click "Choose File"
   → Select: C:\xampp\htdocs\cshop\database\schema.sql
   Click GO (wait for "Import has been successfully finished")

7. Run second file too:
   Click Import again → Choose: database\upgrade_products.sql → Click GO

   ⚠ KNOWN ERROR (FIXED as of June 2026):
   If you see this error during upgrade_products.sql import:
   "ALTER TABLE `products` ADD CONSTRAINT IF NOT EXISTS `fk_product_brand`..."
   This means your MySQL version does NOT support "ADD CONSTRAINT IF NOT EXISTS".
   ✔ The file has already been fixed — just re-import upgrade_products.sql.
   If you already imported it before the fix, do this:
     a) In phpMyAdmin → your database → SQL tab, run:
        ALTER TABLE `products` DROP FOREIGN KEY IF EXISTS `fk_product_brand`;
        ALTER TABLE `products` DROP FOREIGN KEY IF EXISTS `fk_product_subcat`;
     b) Then import upgrade_products.sql again normally.


STEP 4 — Set Up config.php for LOCAL Use
─────────────────────────────────────────
You already have TWO ready-made config files in your project:

   configloc.php  → pre-configured for XAMPP local
   configin.php   → pre-configured for InfinityFree live

For LOCAL use:
   1. Copy configloc.php into C:\xampp\htdocs\cshop\
   2. DELETE configin.php from that folder (or don't copy it)
   3. RENAME configloc.php  →  config.php
   Done! No editing needed — it already has:
      DB_HOST  = localhost
      DB_NAME  = cshop_local
      DB_USER  = root
      DB_PASS  = (empty)
      SITE_URL = http://localhost/cshop
      DEBUG_MODE = true


STEP 5 — Set Folder Permissions (Windows XAMPP)
─────────────────────────────────────────────────
XAMPP on Windows usually doesn't need permission changes, but:
1. Right-click → C:\xampp\htdocs\cshop\uploads\
2. Properties → Security → Edit → Give "Full Control" to your Windows user
3. Click OK


STEP 6 — Access the Site
─────────────────────────
Open browser and go to:
   http://localhost/cshop/

Admin panel:
   http://localhost/cshop/admin/

Default admin login (check your database or reset_admin.php):
   URL: http://localhost/cshop/reset_admin.php
   (Run this once to reset/create admin account)

PART 4 — COMMON ERRORS & HOW TO FIX THEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

─────────────────────────────────────────────────────────────────────────────
ERROR #1: Apache won't start in XAMPP (Port 80 conflict)
─────────────────────────────────────────────────────────────────────────────
CAUSE: Skype, IIS, or another app is using port 80.

FIX OPTION A — Close conflicting app:
  Press Win+R → type: services.msc → Find "World Wide Web Publishing" → STOP it
  Then try starting Apache again.

FIX OPTION B — Change Apache port to 8080:
  In XAMPP Control Panel → Apache → Config → httpd.conf
  Find:  Listen 80
  Change to: Listen 8080
  Also change: ServerName localhost:80
           to: ServerName localhost:8080
  Save → Restart Apache
  Now access site at: http://localhost:8080/cshop/


─────────────────────────────────────────────────────────────────────────────
ERROR #2: MySQL won't start in XAMPP (Port 3306 conflict)
─────────────────────────────────────────────────────────────────────────────
CAUSE: Another MySQL instance is running.

FIX:
  Press Win+R → type: services.msc
  Find "MySQL" or "MySQL80" service → Right-click → STOP
  Now start XAMPP MySQL again.
  
  OR change MySQL port in XAMPP:
  XAMPP → MySQL → Config → my.ini
  Find:  port=3306
  Change to: port=3307
  In config.php (local) change: define('DB_HOST', '127.0.0.1:3307');


─────────────────────────────────────────────────────────────────────────────
ERROR #3: "Access denied for user 'root'@'localhost'"
─────────────────────────────────────────────────────────────────────────────
CAUSE: Wrong DB_PASS in config.php

FIX:
  Local XAMPP root has NO password by default.
  In config.php (local): define('DB_PASS', '');   ← keep empty

  If you set a password for XAMPP root:
  → phpMyAdmin → User Accounts → root → Change password
  → Update config.php accordingly


─────────────────────────────────────────────────────────────────────────────
ERROR #4: "No such file or directory" / "Connection refused" on InfinityFree
─────────────────────────────────────────────────────────────────────────────
CAUSE: Wrong DB_HOST in config.php

FIX:
  1. Log into InfinityFree control panel
  2. Go to MySQL Databases
  3. Look at your database — it shows the EXACT hostname like sql309.infinityfree.com
  4. Copy that EXACT hostname into config.php → define('DB_HOST', ...)
  Do NOT guess — use the exact one shown in your panel.


─────────────────────────────────────────────────────────────────────────────
ERROR #5: White blank page / 500 Internal Server Error
─────────────────────────────────────────────────────────────────────────────
CAUSE: PHP error hidden because DEBUG_MODE is false, or .htaccess issue.

FIX:
  Step 1 — Temporarily turn on debug:
    In config.php: define('DEBUG_MODE', true);
    Reload page — now you'll see the actual error message.

  Step 2 — Common .htaccess issue on InfinityFree:
    InfinityFree supports mod_rewrite but it must be enabled.
    In your .htaccess, the HTTPS redirect might cause issues on free hosting.
    Try commenting it out:
    
    # RewriteCond %{HTTPS} off
    # RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

  Step 3 — After fixing, set DEBUG_MODE back to false.


─────────────────────────────────────────────────────────────────────────────
ERROR #6: Images not uploading / "uploads" folder error
─────────────────────────────────────────────────────────────────────────────
CAUSE: The uploads/products/ folder doesn't exist or has wrong permissions.

FIX (InfinityFree via FileZilla):
  1. In FileZilla, navigate to /htdocs/uploads/
  2. Right-click → Create Directory → name it: products
  3. Right-click on "products" folder → File Permissions
  4. Set to: 755
  5. Check "Recurse into subdirectories" → OK

FIX (XAMPP Local):
  Create folder manually: C:\xampp\htdocs\cshop\uploads\products\
  No permission change needed on Windows.


─────────────────────────────────────────────────────────────────────────────
ERROR #7: "Session not working" / keeps logging out
─────────────────────────────────────────────────────────────────────────────
CAUSE: SITE_URL mismatch or session folder issue.

FIX:
  1. Make sure SITE_URL in config.php matches EXACTLY what's in browser address bar
     (no trailing slash, correct http vs https, correct domain name)
  2. On InfinityFree — sessions work by default, no action needed.
  3. On XAMPP — make sure XAMPP session folder exists:
     C:\xampp\tmp\ (it should exist by default)


─────────────────────────────────────────────────────────────────────────────
ERROR #8: CSS/JS not loading (broken layout/style)
─────────────────────────────────────────────────────────────────────────────
CAUSE: Wrong SITE_URL so asset links are broken.

FIX:
  Make sure SITE_URL is exactly correct:
  Local:  define('SITE_URL', 'http://localhost/cshop');   ← no trailing slash
  Live:   define('SITE_URL', 'https://yourname.great-site.net');

  To check: Right-click broken CSS in browser → Copy link → Compare with SITE_URL


─────────────────────────────────────────────────────────────────────────────
ERROR #9: phpinfo.php or reset_admin.php shows on live site
─────────────────────────────────────────────────────────────────────────────
CAUSE: You accidentally uploaded security-sensitive files.

FIX:
  In FileZilla:
  1. Navigate to /htdocs/
  2. Delete: phpinfo.php
  3. Delete: reset_admin.php
  4. Delete: DEPLOYMENT_GUIDE.txt
  5. Delete: project_summary.txt
  These files expose sensitive info — never leave them on live server!


─────────────────────────────────────────────────────────────────────────────
ERROR #10: "Table doesn't exist" DB error
─────────────────────────────────────────────────────────────────────────────
CAUSE: schema.sql was not imported properly.

FIX:
  1. Go to phpMyAdmin (local or InfinityFree)
  2. Select your database
  3. Click "Import"
  4. Upload schema.sql again → GO
  5. Then upload upgrade_products.sql → GO
  Check the "Tables" count on the left — there should be multiple tables.


─────────────────────────────────────────────────────────────────────────────
ERROR #11: InfinityFree site shows "Error establishing a database connection"
─────────────────────────────────────────────────────────────────────────────
CAUSE: Wrong DB credentials OR database not created yet.

FIX CHECKLIST:
  □ Is DB_HOST exactly matching what InfinityFree panel shows? (e.g. sql313.infinityfree.com)
  □ Is DB_NAME the full name? (e.g. if0_41941799_cshop)
  □ Is DB_USER correct? (e.g. if0_41941799)
  □ Is DB_PASS the password you set when creating the database?
  □ Did you actually CREATE the database in Control Panel → MySQL Databases?
  □ Did you import schema.sql into that database via phpMyAdmin?
  If all yes → wait 5 minutes (InfinityFree sometimes takes time to activate new DBs)


─────────────────────────────────────────────────────────────────────────────
ERROR #12: FTP Upload Fails / FileZilla timeout
─────────────────────────────────────────────────────────────────────────────
CAUSE: Too many files, slow connection, or FTP settings wrong.

FIX:
  1. In FileZilla → Edit → Settings → Transfers → Max simultaneous transfers: 1
  2. Use FTP (not SFTP) — InfinityFree free plan uses plain FTP
  3. Port: 21
  4. If timeout: Edit → Settings → Connection → Timeout: 60 seconds
  5. Upload in batches (folder by folder) instead of all at once
  6. Try using InfinityFree's built-in File Manager as alternative:
     Control Panel → File Manager → Upload files there directly
