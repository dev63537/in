Introduction of Project

Gujju Clothing is a comprehensive, responsive, and database-driven e-Commerce web application developed to provide a seamless shopping experience for apparel, ethnic fashion, western outfits, and lifestyle clothing. The platform connects modern fashion enthusiasts with curated apparel collections across Men, Women, and Kids categories.

The platform addresses the contemporary needs of digital retail by offering an elegant user interface, smooth product discovery, multi-attribute filtering (by Category, Subcategory, Brand, Gender, Price Range, and Size), interactive cart management, dynamic coupon code discounts, and real-time order tracking.

Key Architectural Focus: The project is engineered with high security (Bcrypt password hashing, SQL injection prevention via PDO prepared statements, and session protection) alongside a rich Back-Office Admin Control Suite that provides complete visibility over catalog inventory, low-stock notifications, customer orders, and commercial invoicing.

Core Highlight Features:

  • Multi-Category Catalog: Dynamic categorization across Men's, Women's, and Kids' apparel with multi-angle image galleries.
  • Interactive Shopping Cart: Real-time quantity adjustments, price calculations, and subtotal summaries.
  • Discount Engine: Flexible promotional coupon validation with percentage and flat monetary deductions.
  • Billing & Invoicing: Instant generation of itemized, printable tax invoices with shipping breakdowns.
  • Admin Operations: Unified dashboard with sales metrics, product SKU tracking, brand controls, and order dispatch workflow.

1. System Analysis

System Analysis is the process of examining business workflows, identifying stakeholder needs, and designing a cohesive software solution that satisfies both functional requirements and performance standards.

The analysis for Gujju Clothing was conducted across two primary user groups:

  • Customers / Shoppers: Need a fast, secure, and visually appealing web platform to discover clothing, check size and fabric specifications, manage cart items, apply discounts, and track order fulfillment.
  • Administrators / Store Owners: Require an administrative dashboard to manage inventory levels, receive low-stock alerts, process customer orders, issue commercial invoices, and moderate customer reviews.

The proposed web system bridges these requirements through an intuitive user interface, persistent database storage, and optimized PHP-MySQL architecture.

2. Objective of Project

The primary objectives of the Gujju Clothing web application are:

  • 24/7 Digital Presence: To establish an always-accessible online store eliminating the constraints of physical shopping hours.
  • Rich Product Presentation: To showcase clothing items with multi-image galleries, material details, size guides, and star ratings.
  • Secure User Authentication: To offer secure customer registration, login, profile updates, and encrypted password storage.
  • Streamlined Order & Checkout: To provide a seamless cart-to-checkout pipeline with flexible payment options (COD / Online).
  • Automated Billing & Invoicing: To generate formal itemized invoices with tax and shipping breakdowns.
  • Efficient Admin Management: To equip store administrators with full CRUD control over products, brands, stock, and orders.
  • Cross-Platform Responsiveness: To ensure high responsiveness across mobile phones, tablets, laptops, and desktops.

3. Problem Definition

  • Physical Store Limitations: Traditional retail stores are limited by geographic location and fixed operating hours, making shopping inconvenient for distant or busy customers.
  • Difficult Size & Inventory Lookup: Customers often spend extensive time searching physical racks without knowing whether their specific size or color is in stock.
  • Manual Billing & Inefficiency: Traditional manual billing processes are prone to calculation errors, lack centralized records, and delay customer checkouts.
  • Lack of Real-Time Tracking: Conventional stores cannot provide instant order tracking updates or historical purchase statements to customers.

The Proposed Solution: Gujju Clothing provides an automated, centralized web platform allowing users to browse thousands of apparel styles, verify size availability, apply promo codes, checkout securely, receive instant invoices, and monitor their order delivery status in real-time.

4. Profile Page

The Profile Page is designed to manage and display the personal information and order-related details of the logged-in user. It provides a convenient interface for users to view their account information and track their orders.

Key Features:

  • User Information Management: Displays the user's basic details, including Full Name, Email Address, and Phone Number.
  • Order History: Provides a detailed table containing all previous orders with Order ID, Order Date, Total Amount, Payment Method, and current Order Status.
  • Order Status Tracking: Allows users to track the real-time fulfillment status of their orders, such as Pending, Processing, Shipped, and Delivered.

9. Entity-Relationship (ER) Diagram

Classic Chen's Notation ER Diagram matching your handwritten progress notebook with Entities (Rectangles), Relationships (Diamonds), and Attributes (Ovals) with Primary Keys underlined:

Relational Cardinalities Explained:

  • admins — [manages] — categories / products (1 : N): Store administrators manage categories and apparel listings.
  • users — [adds] — cart (1 : N): Customers store multiple items in their cart session/database.
  • users — [saves] — wishlist (1 : N): Customers bookmark clothing items for later purchase.
  • users — [places] — orders (1 : N): Each customer can place multiple purchase orders.
  • orders — [contains] — order_items (1 : N): Each order is composed of multiple individual apparel items with size and color details.
  • orders — [paid_by] — payments (1 : 1): Every order connects to a transaction/payment record.
  • users — [submits] — contacts (1 : N): Inquiries submitted via the Contact form.
  • users / products — [writes] — reviews (1 : N): Customer star reviews and feedback.
